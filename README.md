# Python Data Analysis & EDA — Store Sales & Business Analysis

## 📌 Project Overview

This project is a practical **Python Data Analysis and Exploratory Data Analysis (EDA)** project focused on understanding store sales performance and identifying meaningful business patterns from the data.

The analysis uses **Python, Pandas, NumPy, and Matplotlib** to clean, explore, analyze, and visualize business data related to stores, customers, sales, operating costs, basket size, and profit.

## 🎯 Project Objectives

* Clean and prepare the dataset for analysis
* Identify and handle missing values
* Detect duplicate records and verify data types
* Clean and analyze categorical variables
* Perform Exploratory Data Analysis (EDA)
* Analyze business metrics using grouping and aggregation
* Examine relationships between numerical variables
* Identify patterns and trends through data visualization
* Generate meaningful business insights from the data

## 🛠️ Tools & Technologies

* **Python**
* **Pandas** — Data cleaning, manipulation, and analysis
* **NumPy** — Numerical and statistical analysis
* **Matplotlib** — Data visualization
* **Jupyter Notebook** — Analysis and documentation

## 🔍 Analysis Performed

### 1. Data Cleaning

* Checked dataset structure and data types
* Identified and handled missing values
* Checked and removed duplicate records where required
* Cleaned categorical data
* Prepared the dataset for further analysis

### 2. Exploratory Data Analysis

Performed descriptive and comparative analysis of key business variables, including:

* Store Type
* Location
* Customers
* Sales
* Operating Cost
* Basket Size
* Profit

### 3. GroupBy & Aggregation

Used Pandas `GroupBy` and aggregation techniques to compare business performance across different store categories and locations.

### 4. Correlation Analysis

Used **NumPy** and correlation analysis to examine relationships between numerical business variables and identify patterns in the dataset.

> Correlation indicates an association between variables; it does not by itself establish causation.

### 5. Data Visualization

Created visualizations using **Matplotlib**, including:

* Bar Charts
* Scatter Plots
* Comparative Visualizations

These visualizations were used to make business patterns and relationships easier to understand.

## 📊 Key Business Areas Explored

The project explores how factors such as **store characteristics, location, customer activity, sales, operating costs, basket size, and profit** relate to overall business performance.

The analysis helps identify patterns that can support data-driven understanding of store performance.
